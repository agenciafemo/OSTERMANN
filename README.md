## 📝 Para Editar

### Mudar Cores
Abra `css/variables.css` e edite as cores no `:root`

### Mudar Texto
Abra qualquer `.html` na pasta e edite o texto

### Mudar Imagens
Substitua arquivos em `assets/images/` e `assets/logos/`

### Mudar Layouts
Edite `css/style.css` para alterar espaçamentos, fontes, etc

## 🆘 Problemas?

### "Não abre quando duplo-clico"
- Clique direito no `index.html` → "Abrir com" → escolha seu navegador

### "Imagens não aparecem"
- Certifique-se de que a pasta `assets/` tem as imagens corretas
- Verifique os caminhos dos arquivos

### "Links não funcionam"
- Todos os links são relativos. Não altere a estrutura de pastas

### "Quer adicionar mais páginas?"
- Copie uma página existente em `pages/`
- Altere o conteúdo
- Adicione link no `header` de `index.html`
